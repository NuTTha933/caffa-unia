## ทดสอบด้วยมือ (หน้าจอ)

- เปิดทุกหน้าด้วยทุก Role แล้วสถานะตอบกลับตรงกับ Access Matrix (200 / 403)
- ตรวจหน้าจอที่ความกว้าง 320, 375, 414, 768 และ 1280 px — ไม่มีการเลื่อนแนวนอน ตาราง ACL / Access Matrix เลื่อนภายในกรอบของตัวเอง

## ปัญหาที่พบระหว่างพัฒนาและวิธีแก้

| ปัญหา | วิธีแก้ |
|---|---|
| ส่งฟอร์มด้วยชื่อ `qty[3]` แล้ว body parser แปลงเป็นอาร์เรย์ ทำให้รหัสเมนูหาย | ใช้ชื่อ `qty[m3]` แล้วตัด `m` ออกที่ Server |
| ข้อความที่ซ่อนไว้สำหรับโปรแกรมอ่านหน้าจอในตาราง Access Matrix ทำให้หน้ามือถือเลื่อนแนวนอนได้ | ให้กรอบตาราง (`.scroll-x`) เป็น `position: relative` |
| ราคาเมนูเปลี่ยนแล้วยอดของออเดอร์เก่าจะเพี้ยน | เก็บชื่อและราคา ณ เวลาสั่งไว้ใน `order_items` |

## ข้อจำกัดของระบบ

- ตรวจสลิปด้วยตาของผู้จัดการ ไม่ได้เชื่อมธนาคารหรือ API ตรวจสลิปจริง
- ไม่มีการแจ้งเตือนแบบเรียลไทม์ ลูกค้าและบาริสต้าต้องรีเฟรชหน้าเพื่อดูสถานะล่าสุด
- จำกัดการเข้าสู่ระบบผิดเก็บในหน่วยความจำของ Server (รีเซ็ตเมื่อเริ่ม Server ใหม่)
- บัญชีพร้อมเพย์ในหน้าแนบสลิปเป็นค่าตัวอย่าง ตั้งได้ใน `.env`
